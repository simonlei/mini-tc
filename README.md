<p align="center"><em>跨平台双栏文件管理器，操作习惯对齐 Total Commander。</em></p>

Windows、macOS、Linux 都能用。左右各一栏，键盘操作优先：复制到对面、批量改名、递归搜索、按内容找重复文件，都有对应的快捷键。

设置、书签、标签页和窗口位置保存在 `~/.minitc/`。

---

## 功能

### 浏览

- 左右双栏。拖动中间分隔条调整宽度，比例会记住；双击分隔条恢复对半。
- 每栏可以开多个标签页，关闭应用后还会在。
- 路径栏可以手改，也可以从盘符下拉切换，并带面包屑。
- 按名称、大小或修改时间排序。名称排序会忽略开头的 `-`，数字按数值比较（`1` < `2` < `10`），中文排在数字和英文字母之后。
- 选中状态跟着文件走。改排序或过滤之后，选中的仍是同一个文件。
- 默认不显示隐藏文件（点开头的名称，以及带隐藏 / 系统属性的文件）。`Ctrl+H` 切换，左右栏各自记住。显示出来的隐藏项是半透明的。
- 名称、大小、类型、修改时间四列都可以拖宽度，双击列边界恢复默认。窗口变窄时，优先保住大小、类型和时间，文件名缩短。
- 新标签页使用设置里的默认排序，已经打开的标签不会被悄悄重排。
- 四套主题：石墨工业、霓虹暗夜、暖茶拿铁、墨竹青翠。
- 记住窗口的位置、大小，以及是否最大化或全屏。
- 从其他程序切回来时，重新列出当前目录，并恢复之前的选中项和键盘焦点。

### 导航

- 每个标签页有自己的访问历史。`Alt+←` / `Alt+→` 后退和前进，鼠标侧键同样；重启后仍能往回走。途中遇到已删除的目录或已拔掉的盘，会跳过并提示。
- `Backspace`，或双击 `..`，返回上一级。
- `Ctrl+D` 把当前目录收进书签（再按一次移除）。左右栏共用同一份列表，可以改名、调整顺序。目录不存在时该行变灰。下拉里还有这个标签页最近去过的目录。
- `Ctrl+Shift+L` 把当前目录记成这个标签页的回家位置，`Ctrl+Y` 跳回去。锁定之后仍可以继续浏览其他目录。

### 文件操作

- `Ctrl+C` / `Ctrl+X` / `Ctrl+V` 与系统剪贴板互通，可以和资源管理器互拷。支持多选和跨盘移动，复制时有进度。同名文件可选跳过或覆盖；同名文件夹会把内容合并进去。
- 复制和移动遇到符号链接、目录联接时会跳过，并在结果里列出，不会跟着链接走下去。
- `F5` 把选中项复制到对面栏的当前目录，`Shift+F5` 则是移动。这两项不经过剪贴板。
- 可以把文件拖到另一栏、拖到 `..`，也可以拖进资源管理器或其他程序。从外部拖进来按复制处理。
- `F2` 改一个名字。`Ctrl+M` 对多选套用同一套规则：查找替换、序号、前后缀、大小写、扩展名。动手之前会标出非法名和重名，有冲突就无法执行。
- `Delete` 移入回收站。一次删掉的多项算一步，`Ctrl+Z` 可以整批恢复。原位置已经有同名文件时，可选改名恢复或跳过。
- `Shift+Delete` 永久删除，不进回收站，也不能撤销。权限不够时会请求管理员权限后再删。
- 删除符号链接或目录联接时，删的是链接本身。
- 在文件上右键可以打开或复制路径；在空白处右键可以新建文件夹。在压缩包上右键可以解压到当前目录，或解压到同名文件夹（使用本机已安装的 7-Zip、WinRAR 或 unzip）。多选多个压缩包时按顺序逐个解压。
- 在 Windows 上，对可执行文件可以「以管理员身份运行」。
- 光标停在文件夹上按 `Space`，大小列显示这个目录的占用。离开该目录后，这个数字不再保留。

### 预览

`Ctrl+Q` 在另一栏预览选中文件，`Esc` 关闭。退出时如果预览开着，下次启动会重新打开它。

- 文本、Markdown、JSON、日志：可以划选复制，也可以一键复制全文。
- 常见图片，以及 HEIC / HEIF。超大的 HEIC 会改用文件里自带的缩小图。连拍、序列和 Live Photo 可以逐帧播放。
- PDF、doc、docx。
- 视频直接播放 `mp4` / `webm` / `mov` 等，可挂同目录字幕或外挂字幕，可调倍速，并记住音量。进度条一直可见。`mkv` / `avi` 等无法解码的格式，以及只有声音没有画面的情况，会改用系统播放器打开。
- 视频播完可以自动播放下一个。
- 「预览时窗口置顶」在通用设置里，默认关闭。打开后，播放视频时整个窗口保持在最前，关掉预览后恢复。

### 查找

- `Alt+F7` 或 `Ctrl+F`：从指定目录按文件名递归查找。多个模式用分号隔开（`*.txt;*.md`），支持 `*` 和 `?`；没有通配符的词按「名字里包含」匹配。还可以再按文件内容筛选。结果边扫边出现，可以随时停止。
- 可以把结果送到左栏或右栏，在那里预览、打开、改名、复制或删除。这个结果标签刷新后消失。
- `/` 只过滤当前这一层目录，和上面的递归搜索相互独立。
- 菜单「重复文件」按内容找出完全相同的文件，分组列出。默认保留修改时间最新的一份，确认之后才把其余副本送进回收站，并可以一次撤销。空文件不参与。文件在确认前被改过的，会跳过不删。

### 设置

- **配置 → 通用设置**：隐藏文件、预览时置顶等应用级选项。
- **配置 → 文件预览设置**：单个文件怎么显示。
- **配置 → 快捷键设置**：查看和修改全部快捷键。可按名称或按键搜索，一个命令可以绑多个键，冲突会标出来。
- **帮助 → 检查更新**：已安装的版本可以在这里升级。

## 快捷键

默认键位如下，都可以在「配置 → 快捷键设置」里改。正在用中文输入法选词时，这些键让给输入法。

| 动作 | 快捷键 |
|---|---|
| 切换左右栏 | `Tab` |
| 预览 / 关闭预览 | `Ctrl+Q` / `Esc` |
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 复制到对面栏 / 移动到对面栏 | `F5` / `Shift+F5` |
| 全选 | `Ctrl+A` |
| 删除（回收站） / 永久删除 | `Delete` / `Shift+Delete` |
| 撤销最近一次回收站删除 | `Ctrl+Z` |
| 重命名 / 批量重命名 | `F2` / `Ctrl+M` |
| 计算目录大小 | `Space` |
| 打开 / 返回上一级 | `Enter` / `Backspace` |
| 后退 / 前进 | `Alt+←` / `Alt+→` |
| 过滤当前目录 | `/` |
| 递归搜索 | `Alt+F7` 或 `Ctrl+F` |
| 添加或移除书签 | `Ctrl+D` |
| 显示隐藏文件 | `Ctrl+H` |
| 新建 / 关闭标签页 | `Ctrl+T` / `Ctrl+W` |
| 下一个 / 上一个标签页 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 锁定标签页 / 回到锁定位置 | `Ctrl+Shift+L` / `Ctrl+Y` |

焦点在地址栏、过滤框或正在改名时，`Ctrl+A` 和 `Ctrl+Z` 作用于文字。焦点在预览正文里时，`Ctrl+A` 选中预览中的文本。

视频预览打开时：`Space` 播放 / 暂停，`←` / `→` 进退 5 秒，`↑` / `↓` 上一个 / 下一个文件，`F` 全屏，`C` 字幕，`M` 静音。

## 下载与安装

安装包在 [GitHub Releases](https://github.com/simonlei/mini-tc/releases)。

Windows 上的 `x64-setup.exe` 没有购买代码签名证书，第一次运行时 Microsoft Defender SmartScreen 可能提示「已保护你的电脑 / 发布者未知」。点击 **更多信息 → 仍要运行** 即可继续。安装包由 [GitHub Actions](https://github.com/simonlei/mini-tc/actions) 公开构建。

## 从源码运行

需要：

- [Rust](https://rustup.rs/) stable（Windows 上为 stable-msvc，1.99.0 及以上）
- [Node.js](https://nodejs.org/) 22.12.0 及以上
- Windows：Visual Studio 2022 Build Tools，含「使用 C++ 的桌面开发」，装在默认路径
- macOS：Xcode Command Line Tools
- Linux：`build-essential`、`libwebkit2gtk-4.1-dev` 等 WebKitGTK 依赖

```bash
git clone https://cnb.cool/simon-lei/mini-tc.git
cd mini-tc
npm install
npx tauri dev
```

也可以用启动脚本（Windows 上在 Git Bash 里运行）。它会探测 Node.js 和 MSVC：

```bash
./dev.sh            # 开发模式
./dev.sh build      # 构建发布版
./dev.sh check      # 仅 cargo check
./dev.sh deps       # 强制 npm install
```

编译环境、Node 版本选择和测试怎么跑，写在 [INTERNALS.md](INTERNALS.md)。

## 发布新版本

1. 同时改 `package.json` 和 `src-tauri/tauri.conf.json` 里的版本号。
2. 提交后打 tag 并推送：`git tag v0.x.0 && git push github v0.x.0`。
3. GitHub Actions 构建 Windows / macOS / Linux 安装包，发布到 [GitHub Releases](https://github.com/simonlei/mini-tc/releases)，并生成带签名的更新清单。
4. 已安装的用户在 **帮助 → 检查更新** 里升级。

本地构建与签名密钥的命令见 [INTERNALS.md](INTERNALS.md)。
