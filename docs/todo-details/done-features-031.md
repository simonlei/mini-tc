  - 实现（纯前端 + 零后端改动，新增 `src/viewState.js` 模块级单例 store，写 `~/.minitc/view-state.json`，150ms 防抖，与 `bookmarks.js` 同构）：`{ showHidden:{left,right}, columnWidths:{size,type,modified}, defaultSortColumn, defaultSortDirection, preview }`。`loadViewState()` 内置 `sanitize()`：列宽按 `COLUMN_LIMITS`（size 50–300 / type 40–200 / modified 80–300）夹取并 `Math.round`，`NaN` 落回默认；`sortColumn` 必须是 `SORT_COLUMNS` 里的键（**故意不含 `found`**——「搜索顺序」只对搜索结果伪目录有意义，不能当普通目录的默认）；`preview` 只接受 `panel`+`kind∈{file,video}`+`path`（**排除 `unsupported`**——那只是「此格式不支持」的占位符，没内容可恢复）。
  - **① 显示隐藏文件**：后端 `is_hidden` 照旧**全量返回**，过滤纯前端——`FileList.vue` 新增 `visibleEntries` computed（`showHidden ? sortedEntries : filter(!is_hidden)`）再喂给 `displayedEntries`，所以切换瞬时生效、大目录也不重新列目录。**每栏独立**（`showHidden` 是 `{left,right}`）：双栏本来用于对比，「左边看点文件、右边看干净的」是合法诉求。**显示出来的隐藏文件仍走 `.is-hidden` 半透明样式**，否则用户会以为是 bug。**⚠️ 选择下标重映射**：`selectedIndices` 是 `displayedEntries` 的下标，过滤会整体平移行号，故 `watch(() => props.showHidden)` 用**条目对象身份**（不是下标）把 `selectedIndices`/`activeIndex`/`anchorIndex` 迁到新列表，并 `emitSelection()`——否则按 Ctrl+H 时第 3 行的选中会静默变成另一个文件，而 `selectedEntry` 正是 Ctrl+Q 预览 / F2 重命名 / Delete 的目标。快照用 `flush:"post"` 的 watcher 维护，保证重映射（默认 pre）读到的还是旧列表。
  - **② 列宽拖拽（新功能）**：表头单元格内绝对定位 `.col-grip`（7px，`col-resize` 光标，hover 泛蓝）——**作为单元格的子元素而非独立 flex item**，否则手柄本身会撑大它要调整的列。拖拽用 `setPointerCapture` + `window` 上的 `pointermove/pointerup/pointercancel`，指针移出手柄或窗口边缘仍跟手，且组件卸载时捕获随之消失（无全局监听泄漏）。宽度通过根元素 `:style` 注入 CSS 变量 `--col-size/--col-type/--col-modified`，对应 CSS 写 `width: var(--col-size, 80px)`——**一次写入同时重排表头和全部行**（可能上千行），而不是给每个单元格挂 `:style`。手柄上的 `@click.stop` 必需：`pointerdown.preventDefault` **不会**阻止后续 click，否则拖完一次列宽会顺手把该列排序切了。**双击手柄 = 恢复该列默认宽度**（`resetColumnWidth(key)`，默认值只在 `COLUMN_LIMITS` 里存一份，`FilePanel` 不硬编码）。
  - **③ 入口**：`Ctrl+H`（`view.toggleHidden`，scope `global`，作用于活动面板，输入框内不认领）→ toast 反馈 + `focusList()`（行集变了，焦点不能留在 `<body>` 上）+ 设置面板「通用设置 → 视图」区块左/右两个独立开关。`GeneralSettingsDialog.vue` 的 schema 从扁平 `ITEMS` 升级为 `GROUPS`（分组）+ 行类型 `toggle`/`select`，新增行是纯声明式的一处改动；行 key 全局唯一。**存储分流按 key 前缀**（`view.` → viewState.js，其余 → app-config.json），对话框因此不需要知道某行属于哪个 store。列宽不在面板里编辑（拖拽 / 双击即更好的交互），面板只放一个说明。
  - **④ 默认排序**：`createTab()` 与 `loadState()` 的归一化默认值都改读 `defaultSortColumn/Direction`。**故意不追溯重排已有 tab**——每个 tab 的排序存在自己的 `tabs-<id>.json` 里，用户已经摆好的 tab 被静默重排是惊吓。
  - **⑤ 预览开关**：App.vue 用一个 `watch`（deep，监听 6 个原始量）→ `setPreviewRestore()`，**不挂在各调用点上**，这样 Ctrl+Q / ↑↓ 切 clip / 自动续播 / Esc / 切面板 / 选中跟随全都自动汇入，磁盘状态不可能与屏幕脱同步。`kind==='unsupported'` 时写 `null`（无内容可恢复，别留路径）。启动时 `restorePreview()` 先 `await loadViewState()`（`consumePreviewRestore()` 读的是它填的值），再等**两个栏都发过 `minitc:panel-listed`** 才应用（否则预览会盖住空面板、背后列表也没选中文件），带 3s兜底超时；随后 `pathExists(path)` 探测——文件在关闭期间被删就跳过恢复。恢复后把**对面栏**（源列表）设为活动栏并 `restoreByNames([name])`，于是 Esc / Ctrl+Q 的行为与「从未关闭过预览」完全一致。`consumePreviewRestore()` 读后即清（内存），但**不写盘**，这样「已恢复但用户还没操作」时崩溃也无害。
