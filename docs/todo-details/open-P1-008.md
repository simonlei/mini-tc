- [ ] **修复：内容搜索对每个候选文件做三次全量拷贝（≤8MB × 3）** — `lib.rs:688/696/700`（现址 `file_contains` 在 `708-732`）。
  - ⚠️ 2026-10-19 取证：三个步骤**逐字仍在**（`718` `fs::read`、`726` `String::from_utf8_lossy`、`730` `to_lowercase()`，后者确实是 Unicode 感知的逐 char 小写变换），**但「三次全量拷贝」是无条件断言、实际是有条件的**：`from_utf8_lossy` 返回 `Cow`，文件是**合法 UTF-8** 时返回 `Cow::Borrowed`，**不产生第二份拷贝**。实际分配数：合法 UTF-8 + 大小写敏感 = **1**；合法 UTF-8 + 不敏感 = **2**；非法 UTF-8 + 敏感 = **2**；非法 UTF-8 + 不敏感 = **3**。原文把最坏路径（非法 UTF-8 + 大小写不敏感）当成了普遍事实。修法不变（改 `BufReader` 分块扫描 + 块间 `needle.len()-1` 字节重叠 + 只对 needle 小写 + ASCII 搜索），`CONTENT_SCAN_LIMIT` 8MB 上限仍在（`528`）。
