  - 实现：① 菜单栏新增「设置」菜单项（`src/App.vue`），点击挂载 `src/components/SettingsDialog.vue`（独立遮罩弹窗）。② 新增通用、可扩展的设置面板：以 `<section>` 区块组织配置项，首个「文本预览后缀」区块列出内置与已启用后缀为可点击 chip（启用态 ✓、禁用态 +，点击切换），含添加输入框（小写去点去非法字符、去重）与「恢复默认」；确定/取消。③ `App.vue` 把 `txt/md/json/log` 从 `PREVIEWABLE_EXTENSIONS` 移出，改由新的 `BUILTIN_TEXT_EXTENSIONS` 默认值 + 用户可编辑的 `textPreviewExtensions`（数组）统一管理——是否文本预览完全由该集合决定（含禁用内置），预览时据此传 `asText` 给后端 `read_file_preview`（后端 `TEXT_EXTENSIONS` 因此被旁路但行为一致，无需改动后端）。④ 持久化改为对象格式 `{ ext: bool }` 保存到 `~/.minitc/text-preview-extensions.json`，以保留「禁用内置」状态；`loadTextPreviewConfig` 兼容旧数组格式（自动并集内置并迁移）。`textPreviewExtensions` 初始即设为内置默认，载入失败也回退内置。⑤ 变更实时对后续预览生效（当前已打开预览不自动刷新）。⑥ 「按文本预览」按钮与设置面板共用同一集合，互不影响。前端改动未跑构建，待用户双击 `dev.bat` 实测。
